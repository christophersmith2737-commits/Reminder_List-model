# Reminder List Model · 清单追踪模板库

为「清单追踪」类 APP（逐项追问模式）提供**标准化的清单模板与规则**，供用户和 AI 直接使用。

## 给 AI 的规则（重要）

请阅读 `TEMPLATE_SPEC.md` 获取完整规范。核心规则如下，AI 生成表格时请严格遵守：

### 通用规则

1. **优先级三档（权重固定）**：必需=权重3 / 推荐=权重2 / 适用=权重1
   - 兼容写法：必需、必须、required；推荐、建议、suggested；适用、日常、daily
   - 星数写法（工作流用）：5★、4★→必需；3★、2★→推荐；1★→适用
2. **排序规则**：优先级高的行写在前面（先全部必需，再推荐，最后适用）
3. **CSV 编码**：UTF-8（建议带 BOM）；逗号分隔；含逗号/换行的字段用双引号包裹
4. **表头**：APP 自动识别中英文列名（见各模板）

### 模板一：购物清单（shopping-list）

Excel 表头：`序号 | 物品名称 | 数量 | 备注 | 优先级`

CSV 表头：`序号,物品名称,数量,备注,优先级`（或英文 `name,quantity,note,priority`）

```csv
序号,物品名称,数量,备注,优先级
1,身份证,1张,报到注册需要，随身携带,必需
2,充电宝,1个,路上手机续航,推荐
```

- 数量：选填，含单位（2瓶/1把），导入后自动显示为「物品名 ×数量」
- 备注：选填（用处、放置位置）

### 模板二：工作流（workflow）

结构与购物清单不同：**第 1 行为任务总名称，第 2 行为表头，第 3 行起为任务**。

```
毕业论文工作流
任务序号,优先级,任务名称,任务备注
1,★★★★★,开题报告,"周五 18:00 前提交导师
需包含研究背景与时间规划"
```

- 优先级用 1~5 颗星（★ 或 ⭐），5★ 最重要
- 任务备注可写 2~3 行（截止时间、任务细节），CSV 中换行需用双引号包裹
- 导入 APP 后星级自动映射：5★、4★→必需；3★、2★→推荐；1★→适用

## 如何导入 APP

1. 下载模板，在 Excel / WPS / 在线表格中填写
2. 另存为 **CSV UTF-8（逗号分隔）**，传到手机
3. APP 中「导入计划（+）」→ 选择文件 → 开始逐项追问
