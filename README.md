# Reminder List Model · 清单追踪模板库

为「清单追踪」类 APP（逐项追问模式）提供**标准化的清单模板与规则**。

## 为什么要有标准模板？

清单追踪 APP 采用「一次只问一项」的追问模式，导入数据需要严格的格式。
把规则写清楚、模板做标准，**其他用户或 AI 生成清单时就不容易出错**，导入后也不会丢数据。

## 优先级三档（核心规则）

| 档位 | 权重 | 含义 |
|------|------|------|
| 必需 | 3 | 最重要，缺失会影响核心目标 |
| 推荐 | 2 | 建议准备，能明显提升体验 |
| 适用 | 1 | 有了更好，没有也不影响大局 |

> APP 兼容写法：必需 / 必须 / required / 3；推荐 / 建议 / suggested / 2；适用 / 日常 / daily / 1

## 通用表结构（5 列）

| 序号 | 物品名称 | 数量 | 备注 | 优先级 |
|------|----------|------|------|--------|
| 1 | 身份证 | 1张 | 报到注册需要，随身携带 | 必需 |

- 物品名称：必填
- 数量：选填（含单位，如 2瓶 / 1把），导入后自动显示为「物品名 ×数量」
- 备注：选填（用处、放置位置等）
- 优先级：必填，三档之一，**优先级高的行写在前面**

## 如何导入 APP

1. 下载模板，在 Excel / WPS / 在线表格中填写
2. 另存为 **CSV UTF-8（逗号分隔）**，传到手机
3. APP 中「导入清单」→ 选择文件，即开始逐项追问

## 给 AI 的规则

AI 为用户生成清单时，请遵循 `TEMPLATE_SPEC.md` 中的完整规范（字段定义、优先级映射、排序规则、输出格式），保证输出可直接导入 APP。
